# Gungnir FM 0.1.5 packages

These x86_64 Linux packages are stored directly in this GitLab repository with Git LFS.

- `Gungnir_FM-x86_64.AppImage`: portable AppImage.
- `gungnir-fm_0.1.5_amd64.snap`: unsigned classic Snap; install with `snap install --dangerous --classic`.
- `org.gungnir.GungnirFM.flatpak`: Flatpak bundle for Freedesktop Platform 26.08.

See the [installation instructions](../README.md#-linux-packages-from-this-gitlab-repository).
Use `git lfs pull` after cloning, then run `sha256sum --check SHA256SUMS` here.
`BUILD-INFO.json` records the source and toolchain used for these builds.
