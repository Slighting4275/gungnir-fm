# File operations and Nemo-style workflows

This change preserves the pending context-menu and terminal improvements and fixes
confirmed defects in file operations, archives, navigation, and controller actions.
It does not establish complete Nemo feature parity or prove the absence of bugs.

## Corrections

- Failed or cancelled local replacements keep the original destination. Copies
  are staged before an atomic exchange, including directory replacements.
- Local and live-daemon transfers reject recursive copies through symlink aliases.
- Cancelling a local listing works while the receiving channel is full; failed
  workers cannot leave the listing feeder blocked.
- Directory-copy read errors propagate instead of silently omitting files, and
  copied directory timestamps are preserved.
- Deleting from an ordinary directory named `files` no longer deletes adjacent
  `.trashinfo` files. Empty Trash reports deletion errors and keeps metadata for
  items it could not remove.
- Mixed Replace and Auto-Rename decisions retain their individual meanings.
  The controller no longer deletes destinations ahead of the transfer.
- Successful live-daemon renames are excluded from cross-filesystem fallback
  copies in mixed move batches. Existing destination directories can be merged.
- Batch rename validates all names and destinations before changing files,
  rolls back completed renames on a later failure, and reports errors. Rename
  chains that require an occupied destination are rejected before any mutation.
- Search previews and terminal-output truncation preserve UTF-8 character
  boundaries instead of panicking on multibyte text.
- Archive extraction validates names and link targets before creating entries,
  resolves archive hard links inside the extraction directory, and never retries
  security failures through a less restrictive extraction command.
- Requested archive encryption cannot silently fall back to plaintext. ZIP and
  7-Zip encryption use the requested container; unsupported combinations fail.
- Archive writers report finalization failures before reporting success or size.
  Existing archive outputs and outputs inside a selected source directory are
  refused; special files and directory-read failures are reported.
- POSIX listings skip names the UTF-8 URI model cannot represent, instead of
  aliasing them to another file. Tar archives preserve raw filename and symlink
  bytes rather than substituting replacement characters.
- URI serialization escapes authorities correctly, and the Gungnir constructor
  preserves literal percent characters in paths.
- Checksum verification preserves filename spaces, stars, and GNU escaped names;
  malformed or empty checksum files report errors.
- Remote listings handle zero batch sizes, cancellation under backpressure, and
  locale-independent GIO type labels. Mock progress retains its transfer ID.
- Selection updates cannot be overwritten by stale prepared row flags. Actions
  operate on visible targets; MIME discovery no longer rereads desktop files on
  every cursor movement.

## Nemo-style controls

The file manager now provides New Window, Duplicate, Invert Selection, Paste Into
Folder, Open in Other Pane, and Ctrl+Shift+N for New Folder, alongside the existing
folder tabs, dual panes, filtering, Trash, properties, and Open With workflows.
Grid arrows follow the actual column count after resizing or zooming.

File clipboard operations exchange `x-special/gnome-copied-files` with compatible
desktop file managers through `wl-copy`/`wl-paste` or `xclip`. Clipboard requests
are serialized. Cancelled or failed cut/paste retains the pending cut for retry;
successful moves remove completed cut items. Copying plain text in another app
suppresses stale internal file selections when the desktop clipboard is readable.
The internal clipboard remains available when desktop clipboard access is absent.

## Validation and limitations

Regression coverage includes failed replacements, symlink recursion, blocked
listing cancellation, real-daemon directory merges and mixed-filesystem moves,
conflict choices, invalid batch renames, Unicode, URI round trips, checksums,
clipboard encoding, cancelled cut/paste, and duplicate/invert selection.
The daemon integration tests build and use the local companion `gungnird`; its
source and wire protocol do not require changes for these fixes.

Local validation includes workspace tests, Nextest, strict Clippy, Miri,
AddressSanitizer, ThreadSanitizer, Valgrind, coverage, mutation tests, and bounded
URI campaigns with both libFuzzer and instrumented AFL++. Detailed tool results
and artifacts remain in the ignored `.bug-check/` directory.

The offline advisory database (2026-10-24) reports maintenance warnings in
transitive dependencies. A current online vulnerability assessment was not run.
Formal-verification attempts exceeded their time bounds and provide no proof.
Standalone LeakSanitizer is restricted by the host's ptrace configuration, which
was preserved. Native libraries constrain sanitizer coverage. Shared binaries
also produce ELF-lint diagnostics that remain documented in the local report.

Full operation-history undo/redo, desktop drag-and-drop interoperability, and
complete Nemo extension parity remain outside this change. Real remote servers
and removable devices were not available for end-to-end validation.
